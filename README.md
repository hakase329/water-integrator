# 水積分器シミュレーター

ルキヤノフの[水積分器（Water integrator）](https://en.wikipedia.org/wiki/Water_integrator)を簡略化した、ブラウザで動くシミュレーターです。
チャンバーの水位を「温度」、管の流れを「熱の流れ」とみなして、熱伝導方程式を水で解く様子を見ることができます。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- タンクを上下にドラッグ: 境界の水位（温度）を変える
- チャンバーをドラッグ: その水位を直接設定する
- バルブをクリック: 管の抵抗を ×1 → ×3 → ×10 → 閉 → ×0.3 と切り替える
- プリセット: 壁の片側加熱 / 両側から冷却 / 中央の熱が広がる / 断熱層のある壁

## モデル

各チャンバーで `A · dh/dt = q入 − q出`、各管で `q = Δh / R` を計算しています。

| 水積分器 | 熱伝導 |
| --- | --- |
| 水位 h | 温度 T |
| チャンバーの断面積 A | 熱容量 |
| 管の抵抗 R | 熱抵抗 |
| 流量 q | 熱流 |
| 定水位タンク | 境界温度 |
